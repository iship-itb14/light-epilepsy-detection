Detection performance

Both networks were tested on all 14 children one at a time, each time by a model that had never seen that child (leave-one-patient-out). The table compares the baseline network with the lightweight one on the full 18 channels. Per-child numbers are the median across the 14 children, so one unusual child cannot move them much.

Bold marks the better of the two where they differ by more than a rounding step.

Seizures caught
A seizure counts as caught if the alarm goes off at any point during it. This is what a carer would notice.
Sensitivity
The share of four-second seizure windows the model flags. It is lower than seizures caught, because one flagged stretch is enough to catch a seizure.
Specificity
The share of ordinary windows left alone. Both models leave over 99% alone.
F1
One number balancing caught seizure windows against false ones. It is low because seizures are so rare that even a few false windows outnumber the true ones.
False alarms per hour
How often the alarm goes off with no seizure. The mean is pulled up by two children with about 15–20 an hour, so the median is the fairer typical figure.
Accuracy
The share of all windows labelled correctly. It looks excellent, but a model that never raises an alarm would score 99.6%, higher than either network, because only 1 window in 236 is a seizure. That is why we do not judge the models by accuracy.

The result. The lightweight network, about 190 times smaller, catches almost as many seizures (80 against 83), catches a larger share of each typical child's seizures, and raises fewer false alarms for the typical child.

Confusion matrices

Each matrix counts every four-second window from the 14 test children, 435,067 in all, after the alarm rule (two of three windows in a row). Rows are what the hospital marked; columns are what the model said.

  • Top left, caught. Seizure windows the model flagged. Highlighted because this is the cell that matters most.
  • Top right, missed. Seizure windows it let pass. About half are missed. A seizure still counts as caught if any of its windows is flagged, which is why about 63% of seizures are caught although only half of seizure windows are.
  • Bottom left, false alarms. Ordinary windows flagged by mistake: about 1 in 66 for EEGNet and 1 in 80 for the CNN. Nearby ones join into a single alarm, so this is far fewer than one alarm per window.
  • Bottom right, left alone. Ordinary windows correctly ignored, the vast majority.

Pooled over all children, so children with more recording weigh more. The per-child medians in the table above weigh each child equally, which is why the two can differ slightly. Counts from results/chbmit/summary.csv.

Size and speed

Size decides whether a model fits on a small chip; speed decides whether it keeps up with the signal. We report both with all 18 channels and with 2 (one on each side, near the ears), before and after converting the weights to 8-bit numbers.

Times are one window at a time on one core of a MacBook Air, median of 200 runs. Each window covers 4 seconds of EEG, so every model is thousands of times faster than it needs to be. On a laptop the 8-bit EEGNet is slower than float, because converting such a tiny model to and from 8-bit costs more than it saves; a chip without float hardware should show the opposite, which we have not measured.

The result. 8-bit storage makes the CNN 3.7 times smaller with no loss in detection, but it still needs about 350 KB. The 2-channel EEGNet is a complete detector in 9.7 KB, 36 times smaller again.

Detection against size

All twelve versions we built: two networks, three channel counts, stored as float or as 8-bit. Across a 400-fold range in file size, seizures caught stay between 77 and 88 of 128.

With one training run per version, differences of a few seizures are within chance. The honest reading is that detection does not fall as the model shrinks, so the smallest version gives up nothing we could measure. Pruning results, which remove weights as well, will be added on the Research page.

Where it went wrong

Most children did well: for six of the 14, both networks caught every seizure, or all but one. The failures are concentrated in a few children, and they are the same for both networks.

The alarm level is chosen on three other children in each round. When one of them is unusually noisy or unusually quiet, the level for the test child ends up too strict or too loose. A short calibration on each wearer, or more children to choose from, would help. The Research page lists every known limit of these results.
