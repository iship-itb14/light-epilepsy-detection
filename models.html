What the models predict

Given four seconds of EEG, is a seizure happening? Both models answer the same question in the same way. The input is one window of 18 channels × 512 samples (four seconds at 128 samples a second). The output is one score between 0 and 1.

Input18 channels × 512 samples, filtered 0.5–40 Hz, each recording scaled by its own typical spread
Outputone score from 0 to 1 (sigmoid)
Flaga window is flagged when its score passes a threshold chosen on validation children, never on the test child
Alarmtwo of the last three windows flagged, so a single odd window does not wake anyone

The score is not a true probability. Training shows the models one seizure window for every four ordinary ones, while real recordings have one in 236, so the threshold, not the raw score, decides what counts as a warning.

The baseline network

What it is. A one-dimensional convolutional network (CNN) with 328,385 weights. It slides short filters along time, each looking at all 18 channels at once, and stacks four blocks of them. After each of the first three blocks the signal is shortened four-fold (512, then 128, 32 and 8 steps), so deeper filters see longer stretches of time. At the end, the network averages each pattern over the whole window, asking "did this pattern appear anywhere?", and turns that into one score.

Why we chose it. It is the plain, reasonably sized network a practitioner would try first: strong on raw signals, easy to explain, and with no tricks specific to EEG. That makes it a fair yardstick for the question this project asks: how much does a much smaller network give up?

How we built it. Keras, in code/seizure/models.py. Every convolution has width 5 and is followed by batch normalisation and ReLU; dropout of 0.5 comes before the output. The first version memorised its nine training children (training loss near zero while the validation score jumped around), so the version in our results adds weight decay (L2, 0.0001) and spatial dropout (0.2, switching off whole feature maps), and is trained with augmented windows: random gain, a little noise, and sometimes one channel set to zero like a loose electrode. These change how it learns, not its size.

The lightweight network

What it is. EEGNet-8,2, a network designed for brain signals by Lawhern and colleagues (2018). Ours has 1,729 weights, about 190 times fewer than the baseline. It treats the window as a small picture, 18 rows of channels by 512 columns of time, and reads it in three steps:

  1. Rhythms. Eight filters, each half a second long, learn which frequency bands matter.
  2. Where on the head. For each rhythm, two filters learn how to combine the 18 channels into one signal. This is done one rhythm at a time (a depthwise convolution), which needs very few weights.
  3. Over time. A separable convolution summarises how each of the 16 signals changes over time, then mixes them. A final layer turns the 256 numbers left into one score.

Why we chose it. It is widely used and cited for EEG, it is built from the start to be tiny, and its steps match how a neurologist reads a recording: rhythm, location, change over time. If a network this small can keep up with the baseline, a detector could fit on a cheap chip in a wearable.

How we built it. Also in code/seizure/models.py, following the published design: batch normalisation after each step, ELU activations, average pooling by 4 and then 8, and dropout of 0.25, the rate the authors suggest when testing on people the model has not seen. Augmentation made EEGNet worse in our tests, so it is trained on plain windows; with so few weights it has little room to memorise in the first place.

Training setup

FrameworkTensorFlow with Keras 3
Lossbinary cross-entropy, seizure windows weighted 2×
OptimiserAdam, learning rate 0.001
Batches256 windows; every seizure window plus 4 ordinary windows for each, ordinary ones redrawn every epoch
Epochsup to 50; stop after 10 without improvement
Best epochthe one catching the most seizure windows on validation children at no more than 1 false alarm per hour
Evaluationleave one child out: 14 rounds, each with 10 training, 3 validation and 1 test child
HardwareMacBook Air, CPU only, one random seed
Time, all 14 roundsabout 4.6 h for EEGNet and 3.4 h for the CNN

Class imbalance. Only one window in 236 is a seizure. A model trained on that mix could say "no seizure" every time and be 99.6% accurate while catching nothing. Balanced batches and the extra weight on seizure windows make sure each step has enough seizures to learn from. Validation and test data are never rebalanced.

What we changed along the way. Every change was chosen by looking at validation children only, never the test children.

StepWhyTest seizures caught, fixed split
First runsRanked windows well, but one alarm level did not suit every childCNN 4 / 22, EEGNet 5 / 22
Scale each recording by itselfChildren differ a lot in signal strengthCNN 13 / 22, EEGNet 17 / 22
Weight decay, spatial dropout, augmentation (CNN)The CNN was memorising its training childrenCNN 13 / 22, false alarms 0.28 → 0.03 / h

The fixed split tested 3 children with 22 seizures and was used while developing. Final results come from leaving each child out in turn (Results page).
