# Listening for Seizures

Lightweight epilepsy detection from EEG, a Neural Networks final project at the University of Colorado Boulder (Fall 2026).

Website: https://iship-itb14.github.io/light-epilepsy-detection/

Team: Sejal Hukare, Ishita Pawar, Swejal Gabhane.

## Editing the site
Teammates: read [CONTRIBUTING.md](CONTRIBUTING.md) before your first edit. It covers running the site locally, the branch workflow, how to add a page, and the design rules.

Quick start: `python3 -m http.server 8000`, then open http://localhost:8000
